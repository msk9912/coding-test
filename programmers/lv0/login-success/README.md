# 로그인 성공?

## 문제

- [프로그래머스 Lv.0 - 로그인 성공?](https://school.programmers.co.kr/learn/courses/30/lessons/120883)

입력한 아이디와 비밀번호를 회원 정보와 비교해 `"login"`, `"wrong pw"`, `"fail"` 중 하나를 반환하는 문제입니다.

## 내 접근

로그인 결과의 기본값을 `"fail"`로 설정했습니다.

회원 정보를 하나씩 확인하면서 아이디가 같을 때만 비밀번호를 비교했습니다. 아이디와 비밀번호가 모두 같으면 `"login"`, 아이디만 같으면 `"wrong pw"`로 결과를 변경했습니다.

## 풀이 흐름

1. `answer`를 `"fail"`로 초기화합니다.
2. `db`에서 회원 정보를 하나씩 꺼냅니다.
3. `id_pw[0]`과 `data[0]`을 비교해 아이디가 같은지 확인합니다.
4. 아이디가 같으면 `id_pw[1]`과 `data[1]`을 비교합니다.
5. 비밀번호까지 같으면 `"login"`, 다르면 `"wrong pw"`를 저장합니다.
6. 같은 아이디가 없다면 기본값 `"fail"`을 반환합니다.

## 핵심 아이디어

찾지 못했을 때 반환할 값을 기본값으로 미리 정해두면 별도의 아이디 존재 여부 변수가 필요하지 않습니다.

또한 문제에서 회원 아이디는 중복되지 않는다고 했으므로, 같은 아이디를 여러 번 만나 결과가 다시 바뀌는 경우는 없습니다.

## 배운 점

- 기본값을 활용하면 ‘끝까지 찾지 못한 경우’를 간단하게 처리할 수 있습니다.
- 아이디 확인 후 비밀번호를 확인하는 중첩 조건문으로 문제의 판정 순서를 그대로 표현할 수 있습니다.
- 문제의 제한사항도 코드가 올바르게 동작하는 이유를 설명하는 근거가 됩니다.
- 오랜만에 힌트 없이 스스로 풀이해 정답으로 통과했습니다.
