# 특이한 정렬

## 문제

- [프로그래머스 Lv.0 - 특이한 정렬](https://school.programmers.co.kr/learn/courses/30/lessons/120880)

정수 `n`과 가까운 수부터 정렬하고, 거리가 같다면 더 큰 수를 앞에 배치하는 문제입니다.

## 처음 접근

거리순과 큰 수 우선이라는 두 조건을 한 번에 표현하는 방식이 낯설어, 각 조건을 나누어 두 번 정렬했습니다. 먼저 숫자를 큰 수부터 정렬한 뒤 `n`과의 거리순으로 다시 정렬했습니다.

## 풀이 흐름

1. `numlist.sort(reverse=True)`로 큰 수부터 정렬합니다.
2. `numlist.sort(key=lambda x: abs(x - n))`로 `n`과 가까운 수부터 다시 정렬합니다.
3. 파이썬 정렬은 안정 정렬이므로, 거리가 같은 숫자들은 첫 번째 정렬에서 만들어진 큰 수 우선 순서를 유지합니다.
4. 정렬된 `numlist`를 반환합니다.

## 핵심 아이디어

파이썬의 안정 정렬은 정렬 기준이 같은 원소들의 기존 순서를 유지합니다. 따라서 보조 조건인 큰 수 우선을 먼저 적용하고, 핵심 조건인 거리순을 나중에 적용할 수 있습니다.

## 복잡도

- 시간 복잡도: `O(m log m)`
- `m`은 `numlist`의 길이입니다.

## 배운 점

- `key=lambda x: abs(x - n)`로 숫자 자체가 아닌 기준값을 만들어 정렬할 수 있습니다.
- 여러 조건을 두 번의 정렬로 나누어 적용할 수 있습니다.
- 안정 정렬 덕분에 두 번째 정렬 기준이 같은 경우 첫 번째 정렬의 순서가 유지됩니다.
- 여러 조건을 나누어 정렬할 때는 우선순위가 낮은 조건을 먼저, 높은 조건을 나중에 적용합니다.
- `list.sort()`는 원본 리스트를 직접 변경합니다.
