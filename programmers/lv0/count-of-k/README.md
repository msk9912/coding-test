# k의 개수

## 내 풀이

```python
def solution(i, j, k):
    answer = 0

    for l in range(i, j + 1):
        while l > 0:
            if l % 10 == k:
                answer += 1
            l //= 10

    return answer
```

## 풀이 아이디어

- `i`부터 `j`까지 숫자를 하나씩 확인한다.
- `l % 10`으로 마지막 자릿수를 꺼내 `k`와 비교한다.
- `l //= 10`으로 확인한 마지막 자릿수를 제거한다.
- 숫자가 0이 될 때까지 반복해 모든 자릿수를 검사한다.

## 잘한 점

이진수 더하기 문제에서 사용했던 `% 10`과 `// 10`을 이번에는 자릿수 검사에 스스로 연결했다. 문자열 변환 없이 각 자릿수를 수학적으로 분리한 정답 풀이이다.

`for`문의 변수 `l`은 다음 반복에서 새로운 숫자를 받으므로, `while`문에서 값을 줄여도 다음 숫자 검사에는 영향을 주지 않는다.

## 문자열로 푸는 짧은 방법

```python
def solution(i, j, k):
    return ''.join(map(str, range(i, j + 1))).count(str(k))
```

범위의 숫자를 모두 문자열로 바꾸고 하나로 합친 다음, `count()`로 `k`가 등장한 횟수를 센다.

예를 들어 10부터 13까지는 `"10111213"`이 되고, 이 문자열에서 원하는 숫자 문자의 개수를 세면 된다.

## 조금 더 읽기 쉬운 문자열 풀이

```python
def solution(i, j, k):
    answer = 0

    for num in range(i, j + 1):
        answer += str(num).count(str(k))

    return answer
```

숫자마다 문자열로 바꾼 뒤 `k`의 개수를 더하므로, 처리 과정을 눈으로 따라가기 쉽다.

## 배운 점

- 숫자의 각 자릿수를 직접 검사할 때: `% 10`, `// 10`
- 문자열 안에서 특정 문자의 개수를 셀 때: `count()`
- 같은 문제도 숫자 연산과 문자열 연산 두 방향으로 접근할 수 있다.
