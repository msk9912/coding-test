# k의 개수

## 문제

- [프로그래머스 Lv.0 - k의 개수](https://school.programmers.co.kr/learn/courses/30/lessons/120887)
- [Notion 풀이 기록](https://app.notion.com/p/3cd258d7cd3b81e48cafc4b9ed0554e9)

정수 `i`, `j`, `k`가 주어졌을 때, `i`부터 `j`까지의 수에 숫자 `k`가 총 몇 번 등장하는지 구하는 문제입니다.

## 내 접근

`i`부터 `j`까지 숫자를 하나씩 확인하면서, `% 10`으로 마지막 자릿수를 꺼내 `k`와 비교했습니다.

확인한 자릿수는 `//= 10`으로 제거하고, 숫자가 0이 될 때까지 반복해 모든 자릿수를 검사했습니다.

## 풀이 흐름

1. `range(i, j + 1)`로 `i`부터 `j`까지 숫자를 하나씩 확인합니다.
2. `l % 10`으로 마지막 자릿수를 꺼냅니다.
3. 마지막 자릿수가 `k`와 같으면 `answer`를 1 증가시킵니다.
4. `l //= 10`으로 확인한 마지막 자릿수를 제거합니다.
5. 숫자가 0이 될 때까지 반복합니다.
6. 모든 숫자의 검사가 끝나면 `answer`를 반환합니다.

## 핵심 아이디어

숫자를 10으로 나눈 나머지는 마지막 자릿수이고, 10으로 나눈 몫은 마지막 자릿수를 제거한 값입니다.

따라서 `% 10`과 `// 10`을 반복하면 숫자의 모든 자릿수를 오른쪽부터 차례대로 검사할 수 있습니다.

## 복잡도

- 확인하는 숫자의 개수를 `n`, 각 숫자의 최대 자릿수를 `d`라고 할 때 시간 복잡도는 `O(n × d)`입니다.
- 추가 공간 복잡도는 `O(1)`입니다.

## 다른 풀이

```python
def solution(i, j, k):
    return ''.join(map(str, range(i, j + 1))).count(str(k))
```

범위의 모든 숫자를 문자열로 바꾸어 하나로 합친 뒤, `count()`로 `k`가 등장한 횟수를 셀 수 있습니다.

이번 기록의 최종 코드는 직접 작성하고 통과한 원래 풀이로 남깁니다.

## 배운 점

- `% 10`으로 숫자의 마지막 자릿수를 꺼낼 수 있습니다.
- `//= 10`으로 확인한 마지막 자릿수를 제거할 수 있습니다.
- 문자열의 특정 문자가 몇 번 등장하는지는 `count()`로 셀 수 있습니다.
- 이전 이진수 더하기 문제에서 사용한 자릿수 연산을 이번 문제에 스스로 연결했습니다.
