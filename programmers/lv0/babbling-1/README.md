# 옹알이 (1)

## 문제

- [프로그래머스 Lv.0 - 옹알이 (1)](https://school.programmers.co.kr/learn/courses/30/lessons/120956)

각 단어가 `"aya"`, `"ye"`, `"woo"`, `"ma"`만 이어 붙여 만들어졌는지 확인하고, 발음할 수 있는 단어의 개수를 구하는 문제입니다.

## 처음 접근

단어마다 허용된 네 발음을 `"#"`으로 바꾼 뒤, 알파벳이 남는지 확인하는 방법으로 접근했습니다.

반복문의 구조는 작성했지만 처음에는 아래처럼 `replace()`의 결과를 다시 저장하지 않았습니다.

```python
word.replace(sound, "#")
```

파이썬 문자열은 불변이므로 `replace()`가 기존 문자열을 직접 수정하지 않습니다. 변경된 새 문자열을 계속 사용하려면 다음처럼 다시 저장해야 합니다.

```python
word = word.replace(sound, "#")
```

## 풀이 흐름

1. `babbling`에서 단어를 하나씩 꺼냅니다.
2. 각 단어에서 `"aya"`, `"ye"`, `"woo"`, `"ma"`를 `"#"`으로 치환합니다.
3. 모든 발음을 바꾼 뒤 `"#"`을 제거합니다.
4. 아무 문자도 남지 않아 빈 문자열이 되면 발음할 수 있는 단어이므로 `answer`를 1 증가시킵니다.

## 핵심 아이디어

허용된 발음을 표시 문자로 바꾸면 마지막에 허용되지 않은 알파벳이 남았는지 쉽게 확인할 수 있습니다.

발음을 바로 빈 문자열로 지우지 않고 `"#"`으로 먼저 바꾸면, 문자를 지우는 과정에서 원래 떨어져 있던 글자들이 붙어 새로운 발음처럼 인식되는 일을 막을 수 있습니다.

## 복잡도

- 단어 수를 `n`, 각 단어의 최대 길이를 `m`이라고 할 때 시간 복잡도는 대략 `O(n × m)`입니다.
- 허용된 발음은 네 개로 고정되어 있습니다.

## 배운 점

- 문자열의 `replace()`는 원본 문자열을 직접 변경하지 않습니다.
- 변경된 문자열을 계속 사용하려면 `word = word.replace(...)`처럼 반환값을 변수에 다시 저장해야 합니다.
- 중첩 반복문에서 바깥 반복문은 단어를, 안쪽 반복문은 허용된 발음을 순회합니다.
- 허용된 문자열을 표시 문자로 치환한 뒤 남은 문자를 검사하는 방법을 사용할 수 있습니다.
