## 내 풀이

```python
def solution(M, N):
    answer = M * N - 1
    return answer
```

## 풀이 아이디어

- 처음에는 종이가 1조각이다.
- 종이를 겹쳐서 자를 수 없으므로 가위질을 한 번 할 때마다 전체 조각 수가 정확히 1개씩 증가한다.
- 최종적으로 필요한 조각 수는 `M * N`개이므로, 필요한 가위질 횟수는 `M * N - 1`번이다.

## 배운 점

최소 횟수 문제에서는 실제 과정을 하나씩 구현하기 전에 **한 번의 행동으로 상태가 얼마나 변하는지** 살펴보면 간단한 식을 찾을 수 있다.

이번 문제는 힌트 없이 한 번에 성공했으므로 복습 우선순위는 낮다.

## 복잡도

- 공간복잡도: `O(1)`
