# 겹치는 선분의 길이

## 문제 요약

세 선분 중 두 개 이상이 겹치는 부분의 전체 길이를 구하는 문제입니다.

## 처음 접근

전체 좌표 범위를 딕셔너리의 key로 만들고, 각 길이 1짜리 구간을 몇 개의 선분이 지나가는지 value에 누적했습니다.

## 풀이 흐름

1. 각 key를 좌표점이 아닌 길이 1짜리 구간 `[key, key + 1]`로 생각했습니다.
2. 처음에는 첫 번째 선분의 시작점과 세 번째 선분의 끝점을 전체 범위로 사용했습니다.
3. 입력 순서가 정렬되어 있다는 보장이 없으므로 `min()`과 `max()`로 실제 범위를 구했습니다.
4. 딕셔너리를 그대로 반복하면 value가 아니라 key가 나온다는 점을 확인했습니다.
5. `result.values()`를 사용해 중첩 횟수가 2 이상인 구간만 세었습니다.

## 핵심 아이디어

선분 `[start, end]`는 `start`부터 `end - 1`까지의 길이 1짜리 구간으로 나눌 수 있습니다. 각 구간의 중첩 횟수를 누적하고 2 이상인 구간의 개수를 세면 겹친 길이가 됩니다.

## 복잡도

전체 좌표 범위의 길이를 `R`이라고 할 때 시간 복잡도는 `O(R)`, 공간 복잡도는 `O(R)`입니다. 이 문제에서는 좌표가 -100부터 100까지라 충분히 작습니다.

## 배운 점

- `min()`과 `max()`를 사용하면 입력 순서와 관계없이 전체 범위를 구할 수 있습니다.
- 딕셔너리를 반복하면 key가 나오고, `.values()`를 사용하면 value가 나옵니다.
- `dictionary[key] += 1`로 구간별 중첩 횟수를 누적할 수 있습니다.
