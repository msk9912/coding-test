# 평행

## 문제 요약

네 점을 두 개씩 이어 만든 두 직선이 평행해지는 경우가 있는지 확인하는 문제입니다.

## 처음 접근

두 점 사이의 기울기를 계산한 뒤, 서로 겹치지 않는 두 선분을 짝지어 기울기가 같은지 비교했습니다.

## 풀이 흐름

1. 처음에는 네 점의 좌표를 각각 변수로 꺼내고 가능한 여섯 기울기를 모두 계산했습니다.
2. 기울기의 절댓값을 비교했지만, 이 방법은 `2`와 `-2`를 같다고 판단한다는 문제를 발견했습니다.
3. `abs()`를 제거해 기울기의 부호까지 비교하도록 수정했습니다.
4. 좌표에 직접 접근하고 반복되는 계산을 `inc(a, b)` 함수로 분리했습니다.
5. 여섯 기울기를 모두 저장하지 않고 실제로 필요한 세 조합만 바로 비교했습니다.

## 핵심 아이디어

평행한 두 직선은 기울기의 크기뿐 아니라 부호까지 같아야 합니다.

## 복잡도

점의 개수가 항상 4개이므로 시간 복잡도와 공간 복잡도는 모두 `O(1)`입니다.

## 배운 점

- 반복되는 계산식은 함수로 분리하면 의도가 더 잘 드러납니다.
- 절댓값을 사용하면 기울기의 방향 정보가 사라집니다.
- 한 번만 사용할 값을 모두 변수로 저장할 필요는 없습니다.
