# 유한소수 판별하기

## 문제

- [프로그래머스 Lv.0 - 유한소수 판별하기](https://school.programmers.co.kr/learn/courses/30/lessons/120878)

분수 `a / b`를 기약분수로 만들었을 때, 분모의 소인수가 2와 5만 존재하는지 확인하는 문제입니다.

## 처음 접근

최대공약수 함수를 사용하지 않고, 분자와 분모를 함께 나눌 수 있는 수를 직접 찾아 기약분수로 만들었습니다. 이후 분모를 2와 5로 반복해서 나누어 다른 소인수가 남는지 확인했습니다.

## 풀이 흐름

1. `div`를 2부터 시작합니다.
2. `a`와 `b`가 모두 `div`로 나누어지면 두 수를 함께 나눕니다.
3. 더 이상 공통으로 나누어지지 않을 때까지 반복해 기약분수를 만듭니다.
4. 약분된 분모에서 2와 5를 반복해서 제거합니다.
5. 분모가 1이 되면 유한소수이므로 1을 반환합니다.
6. 2와 5 이외의 인수가 남으면 무한소수이므로 2를 반환합니다.

## 핵심 아이디어

기약분수의 분모에서 2와 5를 모두 제거했을 때 1이 남으면 유한소수입니다.

## 복잡도

- 시간 복잡도: `O(min(a, b))`
- 공간 복잡도: `O(1)`

## 배운 점

- 유한소수를 판별하기 전에 먼저 분수를 기약분수로 만들어야 합니다.
- 분모의 소인수가 2와 5만 존재하면 유한소수입니다.
- 같은 수로 여러 번 나누어질 수 있으므로, 나누기에 성공했을 때는 `div`를 바로 증가시키지 않습니다.
- 익숙하지 않은 함수를 사용하지 않아도 원리를 이해하고 직접 반복문으로 구현할 수 있습니다.
