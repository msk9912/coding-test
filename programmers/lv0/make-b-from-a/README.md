## 내 풀이

```python
def solution(before, after):
    answer = 0
    if sorted(before) == sorted(after):
        answer = 1
    return answer
```

## 풀이 아이디어

- 이 문제에서는 문자의 순서 자체는 중요하지 않다.
- `before`와 `after`가 각각 어떤 문자를 몇 개 가지고 있는지가 같으면 순서를 바꾸어 만들 수 있다.
- 따라서 두 문자열을 `sorted()`로 정렬한 결과가 같은지 비교한다.

## 배운 점

`sorted()` 함수 자체보다 **순서가 중요하지 않고 구성 원소가 같은지 확인해야 한다면 정렬해서 같은 형태로 만든 뒤 비교할 수 있다**는 패턴을 기억한다.

이번에는 풀이 아이디어에 대한 힌트를 받고 해결했으므로, 비슷한 문제가 나왔을 때 `순서는 상관없다 → 정렬해서 비교해볼까?`를 스스로 떠올릴 수 있는지 복습한다.
