# 이진수 더하기

## 문제

- [프로그래머스 Lv.0 - 이진수 더하기](https://school.programmers.co.kr/learn/courses/30/lessons/120885)
- [Notion 풀이 기록](https://app.notion.com/p/3cc258d7cd3b8100998dd4ea3b70b25d)

이진수 문자열 `bin1`과 `bin2`가 주어졌을 때, 두 이진수의 합을 이진수 문자열로 반환하는 문제입니다.

## 내 접근

두 이진수의 각 자릿수에 `2**b`를 곱해 십진수로 변환한 뒤 더했습니다.

합계를 다시 계속 2로 나누면서 나온 나머지를 문자열 앞에 붙여 이진수로 변환했습니다. 합이 0이면 반복문이 실행되지 않으므로 빈 문자열을 `"0"`으로 바꾸었습니다.

## 풀이 흐름

1. 이진수 문자열을 `int()`로 정수 형태로 바꿉니다.
2. `% 10`으로 마지막 자릿수를 꺼냅니다.
3. 자릿수에 맞는 `2**b`를 곱해 십진수 값에 더합니다.
4. `//= 10`으로 확인한 자릿수를 제거합니다.
5. 변환한 두 십진수를 더합니다.
6. 합계를 2로 나눈 나머지를 `answer` 앞에 붙입니다.
7. 합계가 0인 경우에는 `"0"`을 반환합니다.

## 핵심 아이디어

### 이진수에서 십진수로 변환

오른쪽 끝 자릿수부터 `2**0`, `2**1`, `2**2`를 차례로 곱해 더합니다.

### 십진수에서 이진수로 변환

2로 나눈 나머지는 이진수의 낮은 자리부터 나오므로 다음처럼 기존 문자열의 앞에 붙입니다.

```python
answer = str(total % 2) + answer
```

## 배운 점

- `% 10`으로 마지막 자릿수를 꺼내고 `//= 10`으로 처리한 자릿수를 제거할 수 있습니다.
- 십진수를 2로 계속 나눈 나머지를 모으면 이진수로 바꿀 수 있습니다.
- 문자열은 `+`로 합칠 수 있으며, 나머지가 역순으로 나오므로 앞에 붙여야 합니다.
- 합이 0일 때 결과가 빈 문자열이 되지 않도록 예외 처리가 필요합니다.
